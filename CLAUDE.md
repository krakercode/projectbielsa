# Instructions for Claude working in this repo

This project spans many separate sessions with no memory between them. At the **end of every work session** (before the conversation ends), fill out a session log:

1. Copy `docs/session-log/TEMPLATE.md` to `docs/session-log/YYYY-MM-DD-short-topic.md`
2. Fill it out honestly — see the template's own instructions on what makes a useful entry
3. Commit it alongside the session's other changes

Before starting work, check `docs/session-log/` for the most recent entries — they carry context that isn't in the code (why a call was made, what turned out to be wrong, what's still unverified).
